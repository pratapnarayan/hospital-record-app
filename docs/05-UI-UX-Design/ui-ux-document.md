# UI/UX Design Document

## 🎨 Overview
Defines the design principles and user experience for the Health Record App.

## 🧭 Wireframes & User Flow
- **Patient App:** View records, upload prescriptions, track health data.
- **Doctor Portal:** Manage patients, approve updates.
- **Admin Panel:** System-level access control and monitoring.

## 💅 Design System
- Colors: Calm blues and greens for trust and health.
- Typography: Inter / Roboto.
- Components: Reusable library (React Native UI).

## ♿ Accessibility
- WCAG 2.1 compliance.
- High contrast and screen reader support.

## 📱 Mobile Responsiveness
- Designed mobile-first, responsive up to tablets and desktops.
