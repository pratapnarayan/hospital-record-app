# Testing Strategy

## 🧪 Test Coverage
- Unit testing: Jest
- Integration testing: Supertest
- End-to-end testing: Cypress

## 🧰 Automation Tools
- Postman for API testing.
- Selenium for UI automation.

## ⚙️ Load Testing
- Apache JMeter for stress and performance testing.

## 🔐 Security Testing
- OWASP ZAP penetration testing.
- Vulnerability scans integrated into CI/CD pipeline.
