# Project Plan / Roadmap

## 📅 Milestones
| Phase | Deliverable | Timeline |
|--------|-------------|-----------|
| Phase 1 | MVP (basic record upload, view) | Month 1-2 |
| Phase 2 | AI OCR Integration | Month 3 |

- 2-week sprints.
- Daily stand-ups.
- Review & retrospective at sprint end.

- **AI Engineers** – OCR/NLP pipeline

## ⚠️ Risks & Mitigation
| Risk | Mitigation |
|------|-------------|
| Model accuracy issues | Add feedback loop |
| Data privacy concerns | Strong encryption + audit logs |
| Downtime during release | Blue-green deployment |
